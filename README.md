## AOP-toolkit (aoptk) extension
Extension of the [aoptk package](https://github.com/rdurnik/aoptk).


## Installation

### Install from source (with uv)

```console
git clone git@github.com:rdurnik/aoptk_ext.git
cd aoptk_ext
uv sync --frozen
uv pip install .
```
